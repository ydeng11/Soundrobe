# Offline hosted bootstrap and audit integration

## Goal and approved boundary

Continue the existing disabled native boundary through maintained bootstrap, worker/scoring and auditing. Use fake credentials and in-process responses only. No external dispatch, real credential read, signer provisioning, account change, commit or push is authorized. Preserve the one-attempt limit, 216 slots, 300/600-second scopes and original storage caps/reserves.

## Design

Extend the public rehearsal plan with an optional `offlineHosted` text-pricing evidence object. Its presence selects a separately native-pinned public seed43 test verifier and the disabled hosted context. It is not live authority. Native bootstrap alone constructs the in-process executor; default transport continues rejecting hosted dispatch. The fake credential source is a current-owner-only `.env.local` under `credential-fixture/` beside the public plan, outside the output tree and inside the ignored artifact tree. Its exact public fixture bytes and source binding are checked; this is not the development `.env.local`.

The fake response is constructed natively, never obtained from the provider fixture service. Model settlement therefore has no fixture wire arrival. The driver exports exact per-session native model-operation projections, and the auditor independently joins them to Journal, immutable policy, preparation request, typed worker projection and media readback. Fixture service inventories remain unchanged: 496 actual local arrivals and one distinct native model-response observation settle 497 operations. The original loopback mode remains byte-compatible.

Alternatives rejected: pretending an injected response has a fixture arrival would corrupt the evidence; adding a real HTTP executor with an off flag would expand authority unnecessarily.

## Verifiable sequence

1. Extend existing controls first: optional-plan rejection/roundtrip, new policy signer selection, receipt settlement with a missing model arrival, and exact native offline request/response behavior. Observe failures before implementation.
2. Integrate native context/transport construction in broker bootstrap, select the public seed43 signer in the existing fixture approval helper, and source-lock the fake credential file. Never accept verifier or credential paths in child descriptors.
3. Export native model observations and reconcile them separately from real fixture wire arrivals. Extend existing auditor controls for positive hosted evidence and semantic corruptions; preserve scorer, SQLite, source-lock and completion-authority checks.
4. Run focused controls, existing helper regressions, the serial native server suite, TypeScript/format/syntax/whitespace checks and self-review. Freeze exact source/binary/inputs and run the maintained six-job hosted offline rehearsal within unchanged limits, then audit and privacy-check it.
5. Retain reproducibility hashes, failures and exact scope/limits, update the decision artifact in place, and leave edits uncommitted.
